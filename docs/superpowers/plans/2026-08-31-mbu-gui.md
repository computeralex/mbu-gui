# MBU GUI for Winux Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a PySide6 window plus pkexec helper that wraps Ted Merrill’s MBU 20251115 scripts so a Winux user gets a real app (setup, backup with progress, browse, `.deb`) instead of a silent gnome-terminal click.

**Architecture:** The GUI process always runs as the user. Privileged work goes through `mbu-gui-helper` via PolicyKit. The helper `cd`s into bundled, unmodified MBU scripts and sets Ted’s directory variables so logs/mounts land in the launching user’s `~/.local/share/mbu-gui`. Disk discovery is `lsblk --json` in Python; rsync/boot-fix stay in Ted’s bash.

**Tech Stack:** Python 3.12, PySide6, pytest, PolicyKit (`pkexec`), `lsblk`/`sfdisk`, bundled `vendor/mbu` (mbu-20251115), `dpkg-deb` for Ubuntu 24.04.

**Spec:** `docs/superpowers/specs/2026-08-31-mbu-gui-design.md`

## Global Constraints

- Window process is a normal user; root only via `pkexec` / PolicyKit, and only when the user starts Backup / Apply names / Format / Mount / Unmount.
- Never format, wipe, or `mbuFormatDisk` the disk that contains `/`.
- Never puppet Ted’s interactive prompts; use `mbup ask=n`, `mbuFormatTableWrite`, `mbuFormatDisk`, `mbumount <set>`, `mbuclean`, `sfdisk --part-label`.
- Do not modify files under `vendor/mbu/`.
- Do not look for `~/mbu`; bundled tree only (`vendor/mbu` in dev, `/usr/share/mbu-gui/mbu` when installed). Tests/dev may set `MBU_GUI_MBU_DIR`.
- v1: exactly one connected backup set required to start backup; exactly one disk when preparing a backup disk.
- Legal no-warranty text lives in `LICENSE` only. UI may show operational warnings (unplug; this will erase `sdb`).
- Do not speak for Ted Merrill. Use Ted’s `mbu-icon.png`.
- Python 3.12, PySide6 widgets only. Tests must not wipe real disks.
- Desktop launcher: `Terminal=false`, absolute `Exec=/usr/bin/mbu-gui`, no `Path=mbu`. Click must open the window without PolicyKit.
- Partition set/function names: alphanumeric only; PARTLABEL form `set-function`; unique among attached disks.
- Helper state directories are the **launching user’s** `~/.local/share/mbu-gui/{log,out,mount}`, resolved via `PKEXEC_UID` when running as root.

```python
from __future__ import annotations

from collections.abc import Callable, Mapping
from dataclasses import dataclass
from pathlib import Path
import os
import pwd
from typing import Any


INSTALLED_MBU = Path("/usr/share/mbu-gui/mbu")


@dataclass(frozen=True)
class MbuPaths:
    mbu_dir: Path
    state_dir: Path
    log_dir: Path
    out_dir: Path
    mount_dir: Path
    master_log: Path
    backup_latest_log: Path
    format_latest_log: Path


def _default_mbu_dir(environ: Mapping[str, str]) -> Path:
    env = environ.get("MBU_GUI_MBU_DIR")
    if env:
        return Path(env)
    if (INSTALLED_MBU / "mbup").exists():
        return INSTALLED_MBU
    return Path(__file__).resolve().parents[2] / "vendor" / "mbu"


def resolve_paths(
    *,
    home: Path | None = None,
    mbu_dir: Path | None = None,
    environ: Mapping[str, str] | None = None,
) -> MbuPaths:
    environ = os.environ if environ is None else environ
    home = Path.home() if home is None else home
    mbu_dir = _default_mbu_dir(environ) if mbu_dir is None else mbu_dir
    state_dir = home / ".local/share/mbu-gui"
    log_dir = state_dir / "log"
    out_dir = state_dir / "out"
    mount_dir = state_dir / "mount"
    return MbuPaths(
        mbu_dir=mbu_dir,
        state_dir=state_dir,
        log_dir=log_dir,
        out_dir=out_dir,
        mount_dir=mount_dir,
        master_log=log_dir / "mbu.log",
        backup_latest_log=log_dir / "mbup-latest.log",
        format_latest_log=log_dir / "mbuformat-latest.log",
    )


def home_for_helper(
    *,
    environ: Mapping[str, str],
    getpwuid: Callable[[int], Any] | None = None,
) -> Path:
    getpwuid = pwd.getpwuid if getpwuid is None else getpwuid
    uid_s = environ.get("PKEXEC_UID")
    if uid_s:
        return Path(getpwuid(int(uid_s)).pw_dir)
    if environ.get("HOME"):
        return Path(environ["HOME"])
    return Path.home()
```
